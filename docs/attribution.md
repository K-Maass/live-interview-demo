# Upstream attribution

The original Live Interview desktop edition builds on [Parley](https://github.com/pathorsAI/parley), Apache-2.0, and uses [Argmax WhisperKit](https://github.com/argmaxinc/WhisperKit), MIT, for local speech. The desktop and Swift sources retain the [Parley license](../apps/desktop/src-tauri/notices/Parley-LICENSE) and [WhisperKit notices](../apps/desktop/src-tauri/notices/WhisperKit-NOTICES). Source builds fetch dependencies and models separately.

[TypeSafe Jev](https://typesafe.ai/blog/introducing-system-one-models-and-jev) supplies typed decisions in the managed implementation. The replay uses a simulated provider response. Rights in third-party software remain governed by their respective licenses.
