# Upstream attribution

The original Live Interview desktop edition builds on [Parley](https://github.com/pathorsAI/parley), Apache-2.0, and uses [Argmax WhisperKit](https://github.com/argmaxinc/WhisperKit), MIT, for local speech. This preview ships the application guidance core and provider adapter. It includes neither desktop binaries nor model weights.

[TypeSafe Jev](https://typesafe.ai/blog/introducing-system-one-models-and-jev) supplies typed decisions in the managed implementation. The replay uses a simulated provider response. Rights in third-party software remain governed by their respective licenses.
